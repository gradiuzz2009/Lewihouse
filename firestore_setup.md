# Cloud Firestore Setup & Security Rules Guide for Lewi House

This document outlines the database schema, security rules, index setup, and deployment procedure for the **Lewi House** Firebase Cloud Firestore database (`lewihouse`).

---

## 1. Database Collections & Hierarchy

Firestore operates under a scoped property model (`properties/lewi_house_main`) ensuring multi-unit isolation and consistency with the native Android app (`LewiHouseFirestoreRepository.kt`) and FastAPI sync engine (`firestore_sync.py`).

```
firestore-root/
├── users/
│   └── {userId}                        [User Profiles, Roles: 'admin', 'tenant', 'staff']
│
└── properties/
    └── lewi_house_main/
        ├── rooms/                      [Kosan Room Entities: 101, 102, ...]
        │   └── {roomId}
        ├── residents/                  [Tenant Contracts & Occupancy Details]
        │   └── {residentId}
        ├── payments/                   [Billing, Rent & Utility Payment Records]
        │   └── {paymentId}
        ├── bills/                      [Invoices generated by system]
        │   └── {billId}
        ├── electricity_meters/         [kWh Meter Readings & Photos]
        │   └── {meterId}
        ├── electricity_tokens/         [Purchased PLN / Electricity Tokens]
        │   └── {tokenId}
        ├── maintenance_tickets/        [Tenant Maintenance Complaints & Status]
        │   └── {ticketId}
        ├── service_feedbacks/          [Resident Service Feedback]
        │   └── {feedbackId}
        ├── satisfaction_surveys/       [Periodic Surveys]
        │   └── {surveyId}
        ├── notifications/              [Announcements & Tenant In-App Alerts]
        │   └── {notificationId}
        ├── chat_threads/               [Chat Thread Summaries per Tenant]
        │   └── {tenantId}
        └── chats/
            └── {tenantId}/
                └── messages/           [Real-time Direct Messages]
                    └── {messageId}
```

## 3. How to Deploy to Firebase

### Method A: Deploy via Firebase CLI (Recommended)
Open your terminal in the project root and run:

```bash
# 1. Login to your Firebase account (if not already logged in)
firebase login

# 2. Select the lewihouse project
firebase use lewihouse

# 3. Deploy Firestore rules and indexes
firebase deploy --only firestore:rules,firestore:indexes
```

### Method B: Manual Setup via Firebase Console
1. Navigate to the [Firebase Console](https://console.firebase.google.com/project/lewihouse/firestore).
2. Go to **Firestore Database** > **Rules** tab.
3. Paste the contents of [firestore.rules](file:///c:/Users/AL_AAF/Project/Android%20App/Lewi%20house%20kosan%20management/Lewi%20house-emergent/Lewihouse/firestore.rules) and click **Publish**.
4. Go to the **Indexes** tab and ensure composite indexes from [firestore.indexes.json](file:///c:/Users/AL_AAF/Project/Android%20App/Lewi%20house%20kosan%20management/Lewi%20house-emergent/Lewihouse/firestore.indexes.json) are active.
